# local-tv-show-tracker
Python script and local PWA to better keep track of TV show watch progress locally (accessible to other devices on local network), for when tracking services like Trakt and Letterboxd have a scheme for episodes different to the source you're watching on

## System Requirements
- Linux (ideally), although it *should* work on Windows, given you have the rest of the requirements
  - (if I vibe coded the project from the ground up, surely someone on Windows can add proper support if for some reason it doesn't just work on Windows, but I refuse to boot Windows just to test these scripts)
- Python v3.8 or newer
- Pillow (use `pip install pillow` in your system's terminal if you don't already have it)

## Why is this necessary?
Trakt tends to pick and choose when to split 2 15-minute episodes of a cartoon/show into their own listing, despite the show airing in one 30 minute segment. There is no guarantee that the episodes are in order either. It makes an inconvenient experience for anyone to have to match up the episode titles and find them in a disorganized list *after* they've watched the episode

## Usage
1. Clone/download this repo
2. Run show_tracker.py

## Features & Benefits
- **Customizability** - Show names, covers, descriptions, and watch progress can all be edited
- **Accessibility** - having a PWA allows you to access your progress from any device (see [PWA Info below](https://github.com/sl1pstream/local-tv-show-tracker/tree/main#pwa-info) for more details)
- **Real-time sync** - Changes made to watch progress, both local and through the PWA, will be reflected in real time
- **You choose when and where to run the PWA** - If for some reason port 8080 is already used to host something else, you can change the port number from the python GUI.

## PWA Info
The PWA server is set to port 8080 of the machine running the .py script. **You need to run the python script for the PWA to work since that is only hosted locally**

### Accessing the PWA from the same device running the .py script
In a web browser, visit `http://localhost:8080`

### Accessing the PWA from other devices
In a web browser, visit `http://deviceipaddress:8080` (replace deviceipaddress with the IP address of the device running the .py script)

### Steps to access the PWA remotely
1. Install and set up Tailscale on your host device, the one that will run the .py script while you are away from your (I assume) home network.
2. **Make sure your host device is actively connected to your tailnet. You will not be able to access the PWA otherwise.**
3. On the device you intend to connect to the PWA, log into the same Tailscale account and connect
4. Find the host device's Tailscale IP - just clicking on the name should bring up info including the IP
5. Visit `http://hostdevicetailscaleip:8080` (replace hostdevicetailscaleip with the IP you got from step 5, the port will be the same regardless)

### Installing as an .apk (Android)
There will be nothing under releases, but here's what you can do to create the APK to install for yourself:
1. Install [WebToApp](https://github.com/shiaho777/web-to-app) - your FOSS go-to for turning almost any website into an installable .apk
2. Click "Create App" - "Web"
3. For App Name, put whatever you want. That will appear as the app name on the home screen. The icon can be whatever you want, or it can be nothing
4. For Website URL, either use `https://deviceipaddress:8080` or `https://hostdevicetailscaleip:8080`, depending on your setup (Refer to the sections above)
5. Click "Analyze Site". It should automatically detect the PWA configs. You are free to experiment with the visuals if you choose to do so
6. Click Save
7. On the main screen, click the 3 dots to the right of the app you just created, and click "Build APK", then install. System WebView should work, although I'd recommend GeckoView if you don't care about the app size being slightly larger
